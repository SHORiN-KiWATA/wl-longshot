# wl-longshot

## [ENGLISH](README.md)

A scrolling screenshot tool for Wayland compositors.

![](./pics/showcase.gif)

## Installation

- Arch Linux

    ```
    yay -S wl-longshot-git
    ```

    Then you can simplye run the `wl-longshot`.
